# 旅居村换住权益

本仓库保存旅居村换住权益的领域词汇、交换事件与中文联调样例，并提供一套内存版后端骨架，在统一身份和版本语义下落实核心不变量。

## 资料结构

- `contracts/domain.schema.json`：领域事件的公共信封与稳定枚举。
- `data/`：中文联调样例（房源授权、离线入住）。
- `src/`：公共字段校验与后端骨架代码。
- `tests/`：验证样例符合约定，并覆盖核心业务不变量。

## 后端骨架（src/）

| 模块 | 职责 |
| --- | --- |
| `events.py` | 统一事件信封；`event_id` 全局去重，聚合内 `version` 连续递增 |
| `registry.py` | 房源授权：房屋归属、可住人数、淡旺季额度、管家服务；`provider_of` 供会员核对房源由谁提供 |
| `availability.py` | 房态版本：长期租住、短期换住、房东自用、维修封房在同一房源上互不重叠（半开区间），每次变更提升日历版本 |
| `contracts.py` | 会员合同：年度点数、取消责任、中断补偿偏好；签约即发放年度点数 |
| `points.py` | 点数账户：每笔增减带 `reason_code` 与来源引用，`statement` 供会员逐笔核对 |
| `reservations.py` | 预约占用：跨村预约先全量校验再统一提交（原子确认），任一段失败整体不落占用、不扣点；取消与提前离开按合同责任返还 |
| `checkin.py` | 入住验真：离线受理以 `client_request_id` 为幂等键，恢复联网后重放去重，验真不重复发事件 |
| `privacy.py` | 服务委托与可见范围：同行人、健康偏好仅限本次服务委托可见，房东视图不含会员其他旅程 |
| `maintenance.py` | 维修封房/自然灾害：只查出相应房源相应日期的受影响预约 |
| `compensation.py` | 退改责任：按合同偏好生成替代房、改期或点数返还；原预约只标记 `disrupted`，绝不覆盖 |
| `trace.py` | 全链路追溯：从一次换房追到授权、占用、实际入住与补偿 |

## 核心不变量

1. 同一房源的长租、短换、自用、封房互不重叠；相邻日期（退房当天入住）不算重叠。
2. 跨村预约原子确认：点数不足或任一段日期冲突时，所有村落都不产生占用与扣点。
3. 离线入住凭 `client_request_id` 去重，重放与重复验真不产生重复事件。
4. 维修/自然灾害只影响相应房源的相应日期；补偿生成新的关联预约或点数返还，原预约内容不被覆盖。
5. 同行人与健康偏好只在本次服务委托范围内可见。
6. 点数每笔增减都有原因与来源引用；运营方可从一次换房追到授权、占用、入住与补偿全过程。
